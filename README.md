 AI-Powered Form Automation (n8n)

 Overview

This project is an automated workflow built using n8n to process form submissions, route them based on logic, and update records using AI.

 Features

* Form submission trigger
* Automated record creation
* Rule-based routing (Switch node)
* Role-specific rating updates (Video Editor, Graphic Designer, AI Manager)
* AI Agent integration (Google Gemini)
* Final database update

 Use Case

Designed for teams or agencies to automate handling of incoming requests and assign them efficiently.

 Workflow File

* Import `workflow.json` into n8n to run this project


🛠️ Tools Used

* n8n
* Google Gemini API

 How to Use

1. Open n8n
2. Import the JSON file
3. Configure credentials (API keys, DB)
4. Execute workflow

 Impact

* Reduced manual effort by ~70%
* Improved response time from hours to minutes
